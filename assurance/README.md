Select procedures proportionate to the objective: inquiry, inspection, observation, or reperformance as appropriate. Distinguish design adequacy from operating effectiveness. Specify the population, selected sample, period, and rationale before concluding; disclose limits on assurance.

Use a defined status flow: open → action agreed → in progress → pending verification → closed. Record overdue and risk-accepted items explicitly; acceptance alone does not demonstrate remediation.

## Readiness checklist

- [ ] Scope and criteria approved; obligation versions verified.
- [ ] Controls, populations, owners, and review periods identified.
- [ ] Evidence requests tracked and quality reviewed.
- [ ] Known failures, missing evidence, and disputed findings disclosed.
- [ ] Interviews and access arrangements confirmed.
- [ ] Management responses and corrective actions assigned.
- [ ] Closure requires evidence and an appropriately independent review.
- [ ] Final conclusions state scope, period, sampling, and limitations.

Readiness is preparation for assessment, not a certification or compliance determination.
